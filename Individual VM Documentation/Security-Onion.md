<h1> Purpose </h1>
Security Onion is an OS which comes pre-installed with tools for network security monitoring, log management and analysis, and incident response. This is the main defensive machine of the network, apart from the Sec-Box running Wazuh. However, Security Onion is kept isolated from the domain and is not connected to the DC - a key difference to the Sec-Box. This is done to minimize the risk of compromise. 

<br /> <br />

<h1> Services </h1>
Currently, Security Onion has its base services and nothing additional. 

<br /> <br />

<h1> Troubleshooting </h1>
There were no issues when installing and configuring Security Onion. 

<br /> <br />

<h1> Future Plans </h1>
This machine will be used as part of incident investigations and for network monitoring. It will be a key part of the defense in simulated attacks.
